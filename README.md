# Articulus

> **Technology · Research · Intelligence**

Official website for **Articulus** — a technology and research company focused on building useful digital systems through software engineering, artificial intelligence, research, and automation.

---

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **3D Visualization**: Three.js + React Three Fiber (`@react-three/fiber`) + `@react-three/drei`
- **Design System**: Articulus Dual-Tone Palette (`#080C14`, `#10B981` Emerald, `#2563EB` Cobalt)

---

## Getting Started

### Prerequisites

- Node.js >= 18
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be running locally at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

Previews the compiled distribution:

```bash
npm run preview
```
